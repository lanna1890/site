Componentes de Computadores e Grandezas Elétricas

1.1 Componentes Internos

1.1.1 CPU

A Unidade Central de Processamento (CPU) é o cérebro do computador, responsável por executar instruções e processar dados.

1.1.2 Armazenamento

Dispositivos de armazenamento, como HDDs e SSDs, são usados para salvar dados e arquivos permanentemente.

1.1.3 Memória

A memória RAM é usada pelo sistema para armazenar temporariamente dados que estão sendo processados.

1.1.4 Fonte de Alimentação

A fonte de alimentação converte a energia elétrica da tomada para uma forma utilizável pelos componentes do computador.

1.2 Componentes Externos

1.2.1 Teclado

O teclado é um dispositivo de entrada que permite ao usuário digitar informações no computador.

1.2.2 Monitor de Vídeo

O monitor exibe informações visuais do computador, permitindo a interação com o usuário.

1.2.3 Mouse

O mouse é um dispositivo de entrada que permite ao usuário interagir com o computador apontando e clicando.

1.2.4 Impressora

A impressora é um dispositivo de saída que produz cópias físicas de documentos digitais.

1.2.5 Plotter

Um plotter é um dispositivo de impressão utilizado para produzir gráficos de grande escala, como plantas arquitetônicas.

1.2.6 Scanner

O scanner é um dispositivo de entrada que digitaliza documentos físicos para o formato digital.

1.2.7 Gabinete

O gabinete é a estrutura que abriga os componentes internos do computador, como a placa-mãe, CPU e fonte de alimentação.

1.2.8 Web Cam

A webcam é uma câmera digital conectada ao computador, usada para capturar imagens e vídeos em tempo real.

1.2.9 Caixas de Som

As caixas de som são dispositivos de saída de áudio que reproduzem sons gerados pelo computador.

1.2.10 Microfone

O microfone é um dispositivo de entrada de áudio que captura sons para o computador.
